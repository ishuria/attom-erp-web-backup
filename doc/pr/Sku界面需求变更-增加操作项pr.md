## PR 标题

feat: SKU 界面增加“修改尺寸重量”操作项

## PR 类型

- 功能新增
- 页面交互增强
- 表单校验补充
- 接口对接补充

## 变更背景

SKU 列表页当前已展示 `长(cm)`、`宽(cm)`、`高(cm)`、`重量(g)` 等字段，但缺少直接在列表中维护尺寸重量信息的入口。业务侧需要在 SKU 页面操作列中补充快捷修改能力，减少进入详情页或通过其他路径维护数据的操作成本。

本次 PR 在 SKU 列表页操作下拉菜单中新增 `修改尺寸重量` 操作，并补充弹窗表单、参数校验和保存接口对接能力。

## 本次交付内容

### 1. SKU 列表操作项新增

涉及页面：

- `src/views/productInfomation/skuInfomation/index.vue`

已实施内容：

- 在操作列 `el-dropdown` 下拉菜单中新增 `修改尺寸重量` 操作项
- 点击操作项后，打开尺寸重量编辑弹窗
- 不调整现有 `SKU详情`、`查看HTS`、`SKU复制`、`打包工时`、`交期查看`、`证书` 等已有操作逻辑

### 2. 新增“修改尺寸重量”弹窗

弹窗交互要求：

- 弹窗标题建议为 `修改尺寸重量`
- 弹窗打开时，默认回显当前点击行 SKU 的 `length`、`width`、`height`、`weight`
- 弹窗内容为表单，包含以下 4 个输入项：
  - 长
  - 宽
  - 高
  - 重量
- 弹窗底部包含 `确定` 按钮
- 建议补充 `取消` 按钮，关闭弹窗时不提交数据

### 3. 表单校验规则

字段校验要求：

- `length`、`width`、`height`、`weight` 均为必填
- 仅允许输入 number 类型
- 不允许为空
- 不允许提交字符串类型内容

前端实现建议：

- 使用 `el-form` + `rules` 做统一校验
- 输入组件优先使用 `el-input-number`，从交互层限制非数值输入
- 提交前再次校验，避免空值或异常值绕过 UI 限制

## 字段说明

- 长：对应字段 `length`
- 宽：对应字段 `width`
- 高：对应字段 `height`
- 重量：对应字段 `weight`

回显数据来源：

- 取自当前表格行已有字段 `length`、`width`、`height`、`weight`

## 关键实现说明

### 页面交互

- 用户在 SKU 列表点击某一行操作下拉菜单中的 `修改尺寸重量`
- 系统弹出编辑弹窗，并带出当前行已有尺寸重量数据
- 用户修改后点击 `确定`
- 校验通过后调用保存接口
- 保存成功后关闭弹窗，并刷新当前列表数据或同步更新当前行展示

### 一致性要求

- 弹窗风格与现有页面内其他 `vab-dialog` 交互保持一致
- 表单标签命名与表格列含义保持一致，避免“长宽高重量”口径不统一
- 本次仅新增尺寸重量编辑能力，不修改其他 SKU 操作项行为
- 本次默认沿用现有操作列展示逻辑，不新增独立权限点

## 接口说明

### 保存接口

```http
POST /api/v1/product/update
Content-Type: application/json
```

接口描述：

- Sku-修改Sku尺寸

请求参数：

```json
{
  "id": 1,
  "length": 1,
  "width": 1,
  "height": 2,
  "weight": 3.3
}
```

参数说明：

- `id`：当前 SKU 数据主键 ID
- `length`：长
- `width`：宽
- `height`：高
- `weight`：重量

实现要求：

- 请求方法为 `POST`
- 提交参数使用数字类型
- 不得传递空字符串、字符串数字等非预期类型

## 验证项

- SKU 列表页操作下拉菜单可见 `修改尺寸重量` 操作项
- 点击后可正常弹出编辑弹窗
- 弹窗默认回显当前行 `length`、`width`、`height`、`weight`
- 4 个字段均为必填
- 输入非数字内容时前端可拦截
- 字段为空时不可提交
- 点击 `确定` 后可正确调用 `POST /api/v1/product/update`
- 提交参数中的 `id`、`length`、`width`、`height`、`weight` 与当前编辑行一致
- 保存成功后页面数据可正确更新
- 不影响原有 SKU 列表查询、分页、排序和其他操作项功能

## 影响评估

正向影响：

- SKU 尺寸重量维护路径更短，操作效率更高
- 列表展示与编辑入口形成闭环
- 可减少进入详情页修改的额外成本

潜在风险：

- 若回显字段存在 `null` 或空值，需确认弹窗默认展示与校验行为
- 若接口对数字精度或单位有额外约束，前端需与后端保持一致
- 若保存成功后未刷新列表，可能造成页面展示与后端数据短暂不一致

## 不包含内容

- 批量修改尺寸重量
- 尺寸重量字段单位调整
- 新增独立权限点或操作列权限重构
- 其他 SKU 基础信息编辑能力扩展

## 人工验证步骤

1. 打开 SKU 列表页
2. 任意选择一条有尺寸重量数据的 SKU，点击操作列下拉菜单
3. 点击 `修改尺寸重量`
4. 确认弹窗中的长、宽、高、重量已按当前行数据回显
5. 分别验证空值、非数字、正常数字输入场景
6. 点击 `确定`，确认接口请求参数正确
7. 保存成功后确认列表中对应 SKU 的尺寸重量已更新
