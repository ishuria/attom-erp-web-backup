## 文档定位

本文档为“运营奖金明细新增需求1”的最终实施说明，用于沉淀本次改动的业务目标、实施范围、接口落地方式、交互规则与验收口径，作为 PR 附件与后续维护依据。

## 实施目标

本次改动完成以下两项交付：

- 在运营奖金明细页面新增 `平均小类排名` 展示字段
- 在提成设定的“运营类型”页补充“小类排名配置”能力，用于维护不同档位的额外提成比例

## 实施范围

涉及前端文件：

- `src/views/commission/commissionOperationDetails/index.vue`
- `src/views/commission/commissionCoefficientSetting/index.vue`
- `src/api/devlocal/commission.ts`
- `src/type/commission/commissionType.ts`

不在本次范围内：

- 删除小类排名配置
- 批量导入/导出配置
- 小类排名配置的权限体系调整

## 实施内容

### 1. 运营奖金明细新增字段

页面：`src/views/commission/commissionOperationDetails/index.vue`

实施结果：

- 在运营奖金明细表格中新增 `平均小类排名` 列
- 字段绑定接口返回值 `averageSubcategoryRanking`
- 有值时按原值展示，无值时展示 `-`
- 不改动原有筛选、分页、排序、详情跳转逻辑

展示规则：

- 表头：`平均小类排名`
- 字段：`averageSubcategoryRanking`
- 空值：`-`

### 2. 运营类型新增“小类排名配置”卡片

页面：`src/views/commission/commissionCoefficientSetting/index.vue`

实施结果：

- 在“运营类型”Tab中新增独立 `el-card` 配置区域
- 卡片标题为 `小类排名配置`
- 卡片内新增配置表格，字段为：`档位`、`额外提成比例`
- 页面进入“运营类型”页后拉取配置数据并回显
- 支持编辑额外提成比例并保存
- 支持新增未配置的档位

交互规则：

- 列表按 `gear` 升序展示
- `档位` 为只读字段
- `额外提成比例` 为可编辑字段
- 编辑后通过失焦或确认动作保存
- 保存成功提示成功消息
- 保存失败回滚原值并提示失败
- 新增成功后刷新列表
- 已存在档位不允许重复新增

## 接口落地

### 查询接口

- 描述：运营小类排名配置查询
- URL：`/api/v1/operation/commission/subcategoryRanking/list`
- 方法：`GET`

返回示例：

```json
[
  {
    "id": 1,
    "gear": 1,
    "proportion": 0.01
  }
]
```

### 修改接口

- 描述：运营小类排名配置修改
- URL：`/api/v1/operation/commission/subcategoryRanking/update`
- 方法：`POST`

入参示例：

```json
{
  "id": 1,
  "proportion": 0.02
}
```

返回：`Boolean`

### 新增接口

- 描述：运营小类排名配置新增
- URL：`/api/v1/operation/commission/subcategoryRanking/add`
- 方法：`POST`

入参示例：

```json
{
  "gear": 4,
  "proportion": 0.015
}
```

返回：`Boolean`

## 前端数据处理规则

- 接口中的 `proportion` 使用小数传输
- 页面展示与编辑统一按百分比处理
- 转换规则：`0.01 -> 1`，`1 -> 0.01`
- 比例展示建议统一保留 2 位小数
- 保存提示与现有佣金配置页面保持一致

## 类型与封装要求

- 在 `src/api/devlocal/commission.ts` 中新增对应接口封装
- 在 `src/type/commission/commissionType.ts` 中新增小类排名配置类型
- 如当前运营奖金明细类型声明中未包含 `averageSubcategoryRanking`，需同步补齐字段定义
- 接口命名、返回结构、参数风格与现有 `commission` 模块保持一致

## 验收口径

### 页面展示

- 运营奖金明细页可正确展示 `平均小类排名`
- 空值展示为 `-`
- 不影响现有列表能力

### 配置维护

- “运营类型”页可展示“小类排名配置”卡片
- 列表可正常查询并回显
- 可修改 `额外提成比例` 并保存成功
- 保存失败时可正确回滚
- 可新增未存在的档位配置
- 已存在档位不会重复写入

## 风险与注意事项

- 若后端返回比例精度与前端显示精度不一致，可能产生回显差异
- 若后端未按 `gear` 排序，前端需显式排序
- 若后端未做重复档位校验，前端必须补充防重逻辑
- 当前无删除接口，因此本次实现不包含删除动作
