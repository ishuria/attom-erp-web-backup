# Listing 图片任务变更 PRD

## 1. 文档目标

记录 Listing 图片任务页新增 `美工长期申请` 按钮及相关交互需求。

## 2. 需求背景

### 2.1 Listing 图片任务

现有页面已支持在操作列发起 `超时日期修改申请`。业务要求补充一类新的申请能力，用于长期任务场景，减少线下沟通和人工补录。

## 3. 变更范围

### 3.1 Listing 图片任务页面

- 页面地址：`/Users/luoxiangkai/Project/Worker/attom-web/src/views/newProductTask/listingImageTask/index.vue`

## 4. 需求明细

### 4.1 Listing 图片任务页新增 `美工长期申请`

#### 4.1.1 页面位置

在操作列 `超时日期修改申请` 附近新增一个按钮，按钮名称：`美工长期申请`。

#### 4.1.2 交互逻辑

整体交互与点击 `超时日期修改申请` 基本一致，但有以下差异：

- 去掉 `新的要求完成日期` 输入项
- `申请理由` 必填
- 点击确认后调用新的长期申请接口

#### 4.1.3 接口定义

- url：`/api/v1/artdesign/longTask/apply`
- method：`post`
- params：

```json
{
  "listingTaskId": 1,
  "reason": ""
}
```

字段说明：

- `listingTaskId`：美工图片任务 id
- `reason`：申请理由

#### 4.1.4 接口返回

- `true`：提交申请成功
- `false`：提交申请失败

#### 4.1.5 前端处理要求

- 点击按钮后弹出申请弹窗
- 若 `申请理由` 为空，不允许提交，并给予表单校验提示
- 提交成功后关闭弹窗、提示成功，并刷新列表
- 提交失败时保留弹窗内容，提示失败信息

## 5. 验收标准

### 5.1 Listing 图片任务页

1. 操作列可看到 `美工长期申请` 按钮
2. 点击后可正常打开申请弹窗
3. 弹窗中无 `新的要求完成日期` 字段
4. `申请理由` 为空时无法提交
5. 提交时调用接口 `/api/v1/artdesign/longTask/apply`
6. 成功后提示成功并刷新列表
